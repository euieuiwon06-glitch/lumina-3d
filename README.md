# LUMINA 3D — 첫 번째 숨결

블렌더로 만든 배경 8종과 루미 캐릭터를 그대로 변환한 **360° 3D 웹 데모**. 기준 기획은 `../(추가)LUMINA_초반플레이_통합기획.md`이며, 시작부터 첫 항해 도착까지 한 챕터(약 15~18분)를 끝까지 플레이할 수 있다. 주민 기반 단일 플레이어 데모다(실제 접속자·투표 없음).

- 이전 기준 문서: `../LUMINA_게임기획안_v2.md`, `../01_확정_디자인가이드.md`, `../02_이미지유지_구현명세.md`
- 진행 기록: `IMPLEMENTATION_PLAN.md` · 에셋 한계: `ASSET_GAPS.md` · 2.5D 데모(`../lumina`)는 수정하지 않음

## 실행

```bash
npm install
npm run dev            # http://localhost:5190
npm test               # 퀘스트·교환·항로·저장·조율·보행 격자·점프·길 안내 (17개)
npm run build
node tools/playtest.mjs [--w 1280 --h 720]   # dev 서버 실행 중, 첫 챕터 전체 자동 플레이
```

주소 옵션: `?reset` 저장 지우기 · `?dev` 기본 캐릭터로 바로 시작 · `?dev&scene=overlook` 장면 바로 열기 · `?debug` 보행 격자 표시

## 조작

| 입력 | 동작 |
|---|---|
| WASD·방향키 (Shift 달리기) / 바닥 클릭 | 걷기 · 대상 클릭 시 걸어가서 상호작용 |
| Space | 점프 (낮은 턱 오르기) |
| 드래그 · 휠 · Q/R | 시점 360° 회전 · 거리 · 45° 돌리기 |
| E | 상호작용 · 등불 조율 입력(Space도 가능) |
| Esc | 패널 닫기 · 설정(안내 끄기, 움직임 줄이기, 소리, 조작 안내, 내 모습 바꾸기) |

## 첫 챕터 흐름

| 단계 | 공간 | 플레이 |
|---|---|---|
| 시작 화면 | — | 화면 정중앙 패널: 새 여행 시작 / 이어하기(저장 있을 때) |
| 내 모습 만들기 | — | 불씨형·새싹형·결정형, 몸 색 5, 가슴 빛 4, 심볼 3, 장식, 이름. 회전 미리보기·인사 |
| 멈춘 세계 | 촉수 다리 | 꺼져 가는 등불과 흩어진 판석 다리를 비추는 도입 연출(건너뛰기 가능) |
| Q01 내 안의 작은 빛 | 빛 제작실 | 걷기 → 둘러보기 → 작업대 깨우기 → 색·맥동으로 첫 빛(재료 없음) |
| Q02 친구에게 가는 길 | 캡슐 마을 → 촉수 다리 | 살구와 대화(3갈래) → 첫 등불에 빛 놓기 → 등불 박자 조율 → 흩어진 판석이 날아와 다리가 이어지는 연출 → 직접 건너기 |
| Q03 너의 빛과 나의 빛 | 교환 정원 | 반짝임 3곳 관찰 → 꽃잎 봉오리 깨우기(꽃잎 여섯 장이 열림) → 리본과 교환(주고받는 것 비교·취소 가능, 내 빛 원본 보존) → 두 빛 엮기 |
| Q04 첫 번째 숨결 | 꽃잎 승강대 → 항해 전망대 | 보라와 대화 → 항해 나무에 엮은 빛(빛이 나무→돔→촉수로 흐름) → 태양 정원/얼음 성운 선택 → 항해 연출(첫 항해 약 12초) → 도착 반응 → 조작 회복 순간 챕터 완료 |
| 선택형 | 캡슐 마을·얼음 성운 | 포근의 쉼터(밝기 조절·꽃잎 목도리 보상, 해결 뒤 쉼터에서 쉼), 결정의 노래 |

공간 이동은 세 가지로 구분했다: **빛기둥 문**(멀리서도 보이는 빛기둥, 자주 오간 문은 문턱 통과로 이동), **꽃잎 승강대**(탑승 뒤 꽃잎이 접히고 떠오름), **해파리 항해**(지역 이동).

## 블렌더 → 게임 변환

```bash
node tools/export-all.mjs --bake                 # 8개 장면: 근경 GLB(굽기)·360° 파노라마·보행 격자 (RTX 4060 약 1시간)
node tools/export-all.mjs walkway --bake --no-grid --no-pano   # 한 장면 굽기만 다시
node tools/export-all.mjs --characters           # 캐릭터 6종
```

**재질·색 재현(굽기)**: 각 장면을 Cycles로 정점 색에 굽는다(조명·GI·발광·절차적 무늬 포함). 모서리가 긴 면은 잘게 나눠 빛 변화를 담고, 부드러운 면은 이웃 정점과 평균해 노이즈를 줄인다. 그다음 **블렌더 자체 색 관리(AgX Punchy·노출)를 16비트 PNG 저장/읽기로 적용**해 원본 렌더에서 보이던 색 그대로 저장한다. 웹에서는 조명·톤매핑 없이 그대로 그리고, 파노라마 하늘도 같은 룩으로 구워 서로 맞는다. 캐릭터만 실시간 조명을 쓴다.

## 검증

| 항목 | 방법 | 결과 |
|---|---|---|
| 퀘스트 순서·자동 완료·교환 규칙·항로·도착 완료·쉼터·저장 검증·조율 판정 | `npm test` | 9개 통과 |
| 보행 격자 이동·경로·지면 판정·점프 | `npm test` | 6개 통과 |
| 길 안내(목표 → 다음 출구) | `npm test` | 2개 통과 |
| 첫 챕터 전체(시작 화면 중앙 배치 ~ 새로고침 이어하기·보상 재수령 거부·귀환) | `tools/playtest.mjs` | 최종 실행 결과는 IMPLEMENTATION_PLAN.md |

헤드리스 브라우저(인텔 내장 그래픽)로 검수했다. RTX 탑재 PC에서 사람이 직접 플레이한 조작감 검수는 아직 하지 않았다.

## 알려진 한계

- 굽기는 Cycles 결과라 원본 참고 이미지(EEVEE 렌더)와 간접광 색이 조금 다를 수 있다(제작실이 약간 더 따뜻함).
- 굽힌 빛은 고정이라 시간 변화·움직이는 그림자는 없다. 설치한 빛·등불·결정은 별도 발광 효과로 표현한다.
- 캐릭터는 리그가 없어 파츠 회전 애니메이션만 있다. 장식(목도리·팔찌)은 코드로 만든 형태다.
- 동행은 짧은 따라 걷기, 초대(쉼터 초대)는 포근의 휴식 자세로만 표현했다. 황혼 합류지는 첫 항로에 나오지 않는다(기획: 미구현 지역은 선택지에 표시하지 않음).
